# 可信审计事实、案件与抽样契约

## 目标

平台的核心产物不是“异常列表”，而是一条可重放的审计决策链：

`来源资料 → 数据版本 → 审计总体 → 风险信号 → 抽样计划 → 案件证据 → 程序与结论 → 复核事件`

任何图表、规则、样本、案件和导出结果都必须能回答：

1. 使用了哪个项目、数据版本、分类版本、币种范围和规则版本；
2. 来自哪个公司、会计年度、凭证及源文件行；
3. 针对哪个审计目标和认定；
4. 为什么进入或退出样本；
5. 执行了什么程序、取得了什么证据、由谁作出何种结论。

## 事实身份

### 凭证键

凭证号在不同主体和年度可重复，因此不得单独作为关系键。

- `_voucher_key`：`公司代码 + 会计年度 + 凭证编号`
- `_line_key`：`_voucher_key + 行项目或稳定来源行`
- 缺少公司代码时允许以显式占位符降级，但会计年度仍必须进入键；
- 缺少会计年度时回退到过账日期年度，并记录推断来源；
- 任何降级必须进入数据质量报告，不能静默发生。

### 来源坐标

正式摄入保存原始文件的 SHA-256、原文件名、工作表和原始行号。分析表保留：

- `_source_asset_id`
- `_source_file_hash`
- `_source_sheet`
- `_source_row`
- `_source_column`（列级证据需要时）

### 金额事实

图表、规则、钻取、抽样和导出必须复用同一规范化金额层：

- `_amount_raw`：结合借贷标识和原始正负方向后的净发生额；
- `_amount_abs`：重大性、异常排序等使用的绝对发生额；
- `_amount_currency`：当前金额口径的币种；
- `_amount_basis`：本位币、单一凭证币或其他明确口径。

多种凭证币且无本位币金额时，禁止跨币种合计和跨币种金额排序。

## 三层总体

1. `Population`：审计范围内的完整总体；
2. `RiskSignal`：规则、模型或人工判断产生的完整风险命中；
3. `SampleSelection`：依据抽样计划选出的最终项目。

规则引擎不得按最终样本量截断 `RiskSignal`。抽样计划应明确区分：

- 特定项目全查；
- 风险定向选择；
- 随机、货币单元或分层统计抽样；
- 不可预测探索样本。

风险定向样本不得被描述为可统计推断总体的随机样本。

完整规则命中以规范 JSON 计算 SHA-256，并保存到
`aggregates/rule_runs/<rule_run_id>.json.gz`。`state.json` 只保存汇总和事实文件引用；
抽样、导出和模型辅助核验读取前必须重新校验哈希。规则、数据、分类或币种口径变化后，
当前引用立即失效，历史事实文件保留用于追溯。

覆盖约束属于抽样计划的一部分，不能作为结果生成后的提示项：任何明确设置的月份、
科目或风险信号约束只要未达成，本次选择即失败且不得覆盖上一份有效样本。随机抽样默认
不附加覆盖约束；一旦用户主动增加非概率覆盖条件，界面必须撤销“可直接统计推断”的声明。

## AuditCase

`CandidateGroup` 是案件建议，不是审计结论。正式案件至少包含：

- `AuditCase`：标题、风险、认定、重要程度、负责人、状态；
- `EvidenceRef`：来源坐标、风险信号、附件、管理层解释及反证；
- `AuditProcedure`：拟执行程序和执行结果；
- `Conclusion`：结论、错报或控制偏差、结论人；
- `CaseSnapshot`：数据、分类、币种、规则版本；
- `CaseEvent`：追加式创建、修改、失效、结论和复核历史。

重导、分类或币种范围变化不得删除案件。旧证据应标记为 `stale`，并保留原快照供重放。

证据质量至少分三层：

1. 风险信号（规则命中、图表选中、模型或查询结果）：只能触发程序，不能支持结论；
2. 辅助说明（管理层解释）：可以记录和核验，但不能单独作为实质性结论依据；
3. 可回查证据（来源资产、稳定序时账坐标或反证）：经人工核验并关联认定后，才可进入结论依据。

实质性结论必须与认定判断一致：“未发现异常”要求所有认定均为已支持；错报、控制缺陷、
审计发现等结论至少应有一项认定判断为存在例外。证据不足和范围受限必须保留明确的未解决认定，
且不能进入独立签署。

## 学习边界

无标签序时账只用于学习正常分布、动态阈值、稀有组合和聚类，不直接提供“真实风险”标签。

可用于监督校准的反馈必须是凭证或风险命中级，并绑定数据和规则版本：

- 有效疑点；
- 合理例外；
- 常规机械分录；
- 重复样本；
- 数据或分类问题；
- 证据不足；
- 控制偏差或错报及金额。

LLM 调用失败、解析失败或模型自述不得标记为已确认。

## 验收门槛

- 跨主体、跨年度同号凭证串单为 0；
- 不同币种被直接合计为 0；
- 同一数据、规则、抽样计划和随机种子可复现；
- 完整命中数量不受最终样本量影响；
- 每张最终样本均展示总体、方法、分数构成、入样理由和来源；
- 任一案件可重放版本、证据、程序、结论与事件历史；
- 数据版本变化后案件仍存在，过期证据被明确标记；
- LLM 失败只产生“未核验”，不产生“已确认”；
- 风险样本和统计样本在界面与底稿中分别披露。

## 当前信任边界

- 本地事件链、快照和锚点可发现误改及未同步修改，但锚点仍与案件保存在同一本地项目中；
  它不是外部时间戳、WORM 存储或第三方数字签名。
- `actor` 目前由本地用户输入，尚未绑定企业身份认证；独立复核约束是应用层职责分离，
  不是强身份鉴证。
- MUS 与分层策略当前可用于可复现选样，但尚未保存货币单元重复命中和逐层入样概率，
  因此界面禁止据此执行统计投影。
